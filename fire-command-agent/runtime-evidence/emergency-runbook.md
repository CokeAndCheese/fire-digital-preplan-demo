# 应急手册

status: `PENDING`

## 触发条件

- 固定部署地址健康检查失败；
- 八维通、力量、路线水源或策略 Skill 超时/鉴权失败；
- 真实场景出现非法颜色、对象缺失、路线不可达或三维动作未回执；
- 预案版本、签发或 Word 导出状态与审计记录不一致。

## 处置要求

1. 标记当前案例为 `failed` 或 `pending_manual_review`，保存执行编号、时间和脱敏错误信息。
2. 停止签发、调派和三维自动执行；不得重试到成功为止。
3. 通知值班指挥员和部署负责人，按 `rollback-record-template.json` 记录决定。
4. 只有确认数据源恢复、版本一致且重新验收通过后，才允许恢复发布流程。
