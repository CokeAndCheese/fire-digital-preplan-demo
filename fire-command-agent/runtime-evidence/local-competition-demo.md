## 定位

这是比赛现场使用的本地展示程序，不要求域名、HTTPS 或公网部署。localhost 只承载界面和服务端代理；火情输入、AI/Skill 要素提取、知识库依据、业务智能体编排及远端工具调用由八维通完成，页面负责展示过程、人工复核和结果归档。

## 启动

先在同级 `workbuddy-3d-simulation` 目录启动三维服务：

```powershell
npm run dev
```

再在 `fire-command-agent` 目录启动指挥台（默认即为远端模式）：

```powershell
npm run dev
```

浏览器打开 `http://localhost:3100`。2026-09-01 当前源码验证结果：消防工程 32 个测试文件 / 238 项、三维工程 15 个测试文件 / 132 项、桌面探活 4 项全部通过；两个工程 typecheck 和生产构建通过。真实 WebGL/SDK 和固定案例实时回执仍须现场完成。

## 数据边界

- 当前正式 uStudio 场景 ID：`477747327523254272`。
- 唯一现场参考案例：`baseline/scenario-cases.json`，SHA-256 `c14639097193bed93a2cb1612e013c064a687f52c85c52ca290c065667346d09`。工程中不存在 `baseline/project-baseline.json`，不得再把它列为输入。

- 远端模式通过 `AGENT_RUNTIME_MODE=remote`（默认）启用；界面显示“八维通已连接”。
- `AGENT_RUNTIME_MODE=offline_demo` 仅为开发诊断开关；其结果是版本化演示数据或本地状态机结果，不代表八维通、力量平台、路线水源平台的实时状态。
- 外部数据缺失、字段冲突、人工复核未完成或三维回执不完整时，必须保留 `failed` 或 `pending_manual_review`，不得显示为远端成功。

## 现场演示顺序

1. 输入一个冻结案例，展示 AI/Skill 要素提取。
2. 展示知识库依据、响应等级建议和证据引用。
3. 展示业务智能体生成结构化预案 JSON。
4. 展示人工复核、拒绝/通过边界和审计记录。
5. 展示三维过程、暂停/重放/复位和失败降级状态。
6. 展示结果归档及版本、来源和状态标记。

## 故障降级

八维通或外部受控能力不可用时，展示失败、待人工复核和审计信息；不回退为本地业务成功，不通过固定文案、截图、旧回执或定时器伪造实时结果。开发诊断的离线模式必须另行标记为 `offline_demo`。
